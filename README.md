# 猜数字游戏

一个用 Python 写的命令行小游戏。系统在 1 到 100 之间随机想一个数字，你有 7 次机会把它猜出来。

## 运行

```bash
python guess_number.py
```

无需安装任何依赖，Python 3.x 直接跑。

## 玩法

```
🎮 猜数字游戏开始了！
我已想好一个 1 到 100 之间的数字。
你有 7 次机会猜出它！

第 1 次机会，请输入你的猜测 (1-100): 50
⬇️ 太大了！再试一次。剩余机会: 6
```

猜对就赢，7 次用完会公布正确答案。

## 功能

- 目标数字随机生成，范围 1-100
- 7 次猜测机会
- 每次提示"太大了 / 太小了"并显示剩余次数
- 输入非数字、或超出 1-100 范围时**不消耗机会**
- 用完所有机会后公布答案
